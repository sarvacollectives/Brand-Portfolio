# Sarva Collectives Website

This is a standalone motion-led website for Sarva Collectives.

Open `index.html` in a browser to preview it. The brand logo and founder photo are in `assets/`, the content is in `index.html`, the visual system is in `styles.css`, and the motion field plus scroll behavior are in `script.js`.

Suggested edits before publishing:

- Confirm the two address spellings and PIN codes are exactly how you want them displayed.
- Add product photos later if you want each collection card to become a shoppable/product-led section.
